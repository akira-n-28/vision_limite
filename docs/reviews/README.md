# Revisioni indipendenti

I rapporti sono preservati senza modifiche. Il primo esamina la pipeline v1.0,
il secondo la v1.2; ciascuno dichiara hash e snapshot del codice osservati.
Le righe citate riguardano quelle versioni e non la pipeline corrente.

La [matrice dei rilievi](../REVIEW_ACTIONS.md) indica come la
[pipeline corrente](../../PIPELINE_ADDESTRAMENTO_LIMITE_VL.md) recepisce le osservazioni
e quali implementazioni o verifiche restano necessarie. L'integrazione dei rilievi
non costituisce una nuova revisione indipendente della versione aggiornata.
